
[[Main - GDScript]] 

**Scripts attach to a node and extend its behavior**. This means that [[Scripts - Godot|scripts]] inherit all [[Functions - GDScript|Functions]] and properties of the [[Nodes - Godot|node]] they attach to.

Godot offers **four gameplay programming languages**: GDScript, C#, and, via its GDExtension technology, C and C++. There are more community-supported languages, but these are the official ones.

You can use multiple languages in a single project.

Every GDScript file is implicitly a class. The `extends` keyword defines the class this script inherits or extends
